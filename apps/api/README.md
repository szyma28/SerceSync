# SerceSync API

NestJS backend for SerceSync.

It serves authentication, shifts, handovers, residents, manager dashboards, and audit workflows for the Flutter clients.

## Setup

```bash
pnpm install
```

## Run

```bash
pnpm run start:dev
```

## Verify

```bash
pnpm run build
pnpm run test
pnpm run test:e2e
```
